# מעקב משימות אישי

גרסת MVP ראשונה לאפליקציית משימות אישית בעברית ובכיוון RTL.

## מה כבר עובד

- כל המשימות ההיסטוריות והפתוחות שנאספו בשיחה.
- מזהים קבועים מסוג P ו-W.
- זיהוי שקול של P19, P019 ו-P-019 בחיפוש.
- הוספת משימה עם המספר הבא ברצף.
- שינוי סטטוס וסימון מהיר כבוצעה.
- חיפוש וסינון.
- שמירה מקומית בדפדפן באמצעות localStorage.
- ממשק רספונסיבי למחשב ולנייד.

## הרצה מקומית

```bash
npm install
npm run dev
```

פתחו http://localhost:3000.

## השלב הבא ב-Codex

1. חבר Supabase לפי `supabase/schema.sql` ו-`.env.example`.
2. הוסף התחברות באמצעות Google או magic link.
3. העבר את המשימות מ-localStorage למסד הנתונים, תוך שמירת המזהים.
4. הוסף עריכת פרטים, תאריך יעד והערות.
5. הוסף PWA מלאה עם service worker ואייקונים.
6. פרוס ל-Vercel וחבר דומיין קבוע.
