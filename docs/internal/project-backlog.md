# Backlog פנימי מרכזי

מטרת הקובץ: רשימת כל המשימות הפתוחות, מחולקות לחבילות, כולל עדיפות והערכת היקף. זה מקור האמת לפני כל סבב עבודה.

## סטטוסים

- לא התחיל
- בתכנון
- בוצע חלקית
- ממתין למשתמש
- נדחה כרגע

## שיערוך היקף לפי חבילות

ההערכות הן באחוזים מתוך הקצאת טוקנים יומית/שבועית זמינה, ונועדו לעזור בתעדוף. הן אינן התחייבות מדויקת.
