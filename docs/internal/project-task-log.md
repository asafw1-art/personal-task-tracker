# יומן ביצוע פנימי

מטרת הקובץ: מקור אמת למה שכבר בוצע או תוקן בפרויקט, כדי לא לחזור על אותה עבודה כמה פעמים. הקובץ אינו חלק מממשק המשתמש.

## כללי עדכון

- לעדכן אחרי כל שינוי משמעותי, commit, סקריפט Supabase או החלטת מוצר שסוגרת משימה.
- אם פעולה היא זמנית, לציין זאת במפורש ולהשאיר את הפיצ'ר העתידי פתוח ב-`project-backlog.md`.
- לא להכניס secrets, מפתחות, טוקנים או מידע פרטי שאינו נחוץ.
